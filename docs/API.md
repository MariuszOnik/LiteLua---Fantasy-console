## Core

Cart callbacks, screen constants and timing.

### `_init` — callback

```lua
_init()
```

Called once after main.lua has been loaded, before the first frame.

Example:

```lua
function _init()
  x, y = 128, 96
end
```

### `_update` — callback

```lua
_update()
```

Called once per game frame (30 times per second), before drawing. Put game logic and input handling here.

Example:

```lua
function _update()
  if btn("left") then x = x - 2 end
  if btn("right") then x = x + 2 end
end
```

### `_draw` — callback

```lua
_draw(screen)
```

Called for each screen once per game frame, after _update: first with TOP, then with BOTTOM.

| Argument | Type | Description |
|---|---|---|
| `screen` | integer | TOP (0) or BOTTOM (1) |

Example:

```lua
function _draw(screen)
  if screen == TOP then
    -- draw the game
  else
    -- draw the map or the HUD
  end
end
```

### `TOP` — const

```lua
TOP
```

Top screen id (0), passed to _draw.

### `BOTTOM` — const

```lua
BOTTOM
```

Bottom (touch) screen id (1), passed to _draw.

### `print`

```lua
print(...)
```

Writes the values to the text console and to the log file litelua/log.txt on the SD card.

| Argument | Type | Description |
|---|---|---|
| `...` | any | values, separated by tabs |

Example:

```lua
print("score", score)
```

### `log`

```lua
log(...)
```

Writes the values only to the log file litelua/log.txt on the SD card, with the time since start. The file is saved once per frame; logging every frame slows the game down.

| Argument | Type | Description |
|---|---|---|
| `...` | any | values, separated by tabs |

Example:

```lua
log("enemy spawned at", x, y)
```

### `micros`

```lua
micros() -> integer
```

Time counter for measuring code speed. Wraps around after about 128 seconds, so only use it for short intervals.

Returns: integer — microseconds since boot

Example:

```lua
local t = micros()
heavy_work()
print("took " .. (micros() - t) .. " us")
```

## Input

Buttons and the touch screen. Sampled once per game frame.

### `btn`

```lua
btn(name) -> boolean
```

Button names: a b x y l r start select up down left right touch. "touch" means the screen is touched. An unknown name is an error.

| Argument | Type | Description |
|---|---|---|
| `name` | string | button name, see below |

Returns: boolean — true while the button is held

Example:

```lua
if btn("left") then x = x - 1 end
if btn("right") then x = x + 1 end
```

### `btnp`

```lua
btnp(name) -> boolean
```

Use for actions that should happen once per press (jump, menu).

| Argument | Type | Description |
|---|---|---|
| `name` | string | button name |

Returns: boolean — true in the frame the button was pressed

Example:

```lua
if btnp("a") then jump() end
```

### `btnr`

```lua
btnr(name) -> boolean
```

Use for actions on release, e.g. charged shots.

| Argument | Type | Description |
|---|---|---|
| `name` | string | button name |

Returns: boolean — true in the frame the button was released

Example:

```lua
if btn("b") then charge = charge + 1 end
if btnr("b") then shoot(charge); charge = 0 end
```

### `touch`

```lua
touch() -> x, y | nil
```

Returns the stylus position while the screen is touched, otherwise nil.

Returns: integer — x on the bottom screen (0-255); integer — y on the bottom screen (0-191)

Example:

```lua
local tx, ty = touch()
if tx then
  px, py = tx, ty
end
```

## Graphics

Drawing shapes and images. Call these in _draw; the screen is redrawn every frame. Colors: 0-15 = palette, or 0xRRGGBB.

### `cls`

```lua
cls([col])
```

Clears the screen with a color. Also covers everything drawn before it in this frame. Call it first in _draw.

| Argument | Type | Description |
|---|---|---|
| `col` | color | background color, default 0 |

Example:

```lua
function _draw(screen)
  cls(1)
end
```

### `color`

```lua
color([col])
```

Sets the color used by drawing functions called without one.

| Argument | Type | Description |
|---|---|---|
| `col` | color | new default color, default 12 |

Example:

```lua
color(8)
rect(10, 10, 20, 20)
```

### `alpha`

```lua
alpha([a])
```

Sets the opacity of everything drawn after it. The DS has 32 levels. Call alpha() to go back to opaque.

| Argument | Type | Description |
|---|---|---|
| `a` | number | 0 (invisible) .. 1 (opaque), default 1 |

Example:

```lua
alpha(0.5)
circfill(64, 64, 20, 8)
alpha()
```

### `camera`

```lua
camera([x, y, [zoom]])
```

Moves and zooms the view: everything drawn after it appears at (position - camera) * zoom. camera() resets it. Use it to scroll the world and reset it before drawing the HUD. Lines and outlines stay 1 pixel wide when zoomed.

| Argument | Type | Description |
|---|---|---|
| `x` | number | world x shown at the left edge, default 0 |
| `y` | number | world y shown at the top edge, default 0 |
| `zoom` | number | scale 1/16 .. 16, default 1 |

Example:

```lua
camera(player.x - 128, player.y - 96)
draw_world()
camera()
draw_hud()
```

### `clip`

```lua
clip([x, y, w, h])
```

Draws only inside this screen rectangle (the camera does not move it). clip() draws on the whole screen again.

| Argument | Type | Description |
|---|---|---|
| `x` | number | left edge on the screen |
| `y` | number | top edge on the screen |
| `w` | number | width |
| `h` | number | height |

Example:

```lua
clip(8, 8, 100, 50)
draw_map()
clip()
```

### `image`

```lua
image(name, [fw, fh]) -> image
```

Loads gfx/<name>.png of the cart into video memory. With a frame size the image is a sheet of frames numbered from 0, left to right, top to bottom. Loading the same name again returns the same image. PNG with a palette of up to 16 or 256 colors uses the least memory; palette index 0 (or alpha 0) is transparent. Images are at most 1024x1024; video memory holds 256 KB.

| Argument | Type | Description |
|---|---|---|
| `name` | string | file in gfx/ without .png, e.g. "hero" |
| `fw` | integer | frame width (optional) |
| `fh` | integer | frame height, default fw |

Returns: image — the image; fields w, h (frame size) and frames

Example:

```lua
hero = image("hero")
walk = image("walk", 16, 16)
print(walk.frames)
```

### `sub`

```lua
sub(img, x, y, w, h, [fw, fh]) -> image
```

Makes an image from a part of another one, without copying: it uses the same video memory. Works everywhere an image does.

| Argument | Type | Description |
|---|---|---|
| `img` | image | source image |
| `x` | integer | left of the part |
| `y` | integer | top |
| `w` | integer | width |
| `h` | integer | height |
| `fw` | integer | frame width (optional) |
| `fh` | integer | frame height, default fw |

Returns: image — an image showing only that part

Example:

```lua
tiles = image("tiles")
door = sub(tiles, 32, 0, 16, 24)
spr(door, 100, 80)
```

### `spr`

```lua
spr(img, x, y, [frame], [flip])
```

Draws an image (or one frame of it) with its top left corner at x, y.

| Argument | Type | Description |
|---|---|---|
| `img` | image | image to draw |
| `x` | number | left |
| `y` | number | top |
| `frame` | integer | frame number from 0, default 0 |
| `flip` | string | "x", "y" or "xy" to mirror |

Example:

```lua
spr(walk, x, y, t // 6 % walk.frames)
spr(walk, x, y, 0, "x")  -- facing left
```

### `sprx`

```lua
sprx(img, x, y, [frame], [angle], [sx], [sy], [flip])
```

Draws an image rotated and scaled around its center x, y. Positions can have fractions.

| Argument | Type | Description |
|---|---|---|
| `img` | image | image to draw |
| `x` | number | center x |
| `y` | number | center y |
| `frame` | integer | frame number from 0, default 0 |
| `angle` | number | rotation in degrees, clockwise, default 0 |
| `sx` | number | horizontal scale, default 1 |
| `sy` | number | vertical scale, default sx |
| `flip` | string | "x", "y" or "xy" to mirror |

Example:

```lua
sprx(ship, x, y, 0, angle)
sprx(coin, 64, 40, 0, 0, 2)  -- twice as big
```

### `sspr`

```lua
sspr(img, sx, sy, sw, sh, dx, dy, [dw], [dh], [flip])
```

Draws any part of an image, stretched to dw x dh. A negative dw or dh mirrors it.

| Argument | Type | Description |
|---|---|---|
| `img` | image | source image |
| `sx` | integer | part left |
| `sy` | integer | part top |
| `sw` | integer | part width |
| `sh` | integer | part height |
| `dx` | number | screen left |
| `dy` | number | screen top |
| `dw` | number | drawn width, default sw |
| `dh` | number | drawn height, default sh |
| `flip` | string | "x", "y" or "xy" to mirror |

Example:

```lua
sspr(tiles, 0, 0, 8, 8, 10, 10, 32, 32)
```

### `tint`

```lua
tint([col]) / tint(c1, c2, c3, c4)
```

Colors the images drawn after it: white keeps the image as it is, other colors darken and tint it. Four colors make a gradient over the corners. tint() removes it. Shapes are not affected.

| Argument | Type | Description |
|---|---|---|
| `col` | color | color multiplied with the images drawn next |
| `c1..c4` | color | corners: top left, top right, bottom right, bottom left |

Example:

```lua
tint(2)              -- red flash when hit
spr(hero, x, y)
tint()
```

### `text`

```lua
text(s, x, y, [col])
```

Draws text with the built-in font: every character is 6x8 pixels (42 columns x 24 rows fit on a screen). ASCII and the Polish letters are included; other characters show as a box. Works with camera (also zoom), clip and alpha.

| Argument | Type | Description |
|---|---|---|
| `s` | string | text; \n starts a new line, \t goes to the next multiple of 4 columns |
| `x` | number | left |
| `y` | number | top |
| `col` | color | color, default: color() |

Example:

```lua
text("Score: " .. score, 2, 2, 12)
text("Zażółć gęślą jaźń", 2, 12, 4)
```

### `textw`

```lua
textw(s) -> w, h
```

Measures text, e.g. to center it or draw a box behind it.

| Argument | Type | Description |
|---|---|---|
| `s` | string | text |

Returns: integer — width in pixels of the longest line; integer — height in pixels of all lines

Example:

```lua
local w = textw(msg)
text(msg, (256 - w) // 2, 90)
```

## Files

Reading cartridge files, saving data and loading modules. Paths are relative to the cartridge, "save/..." is the save folder.

### `io.open`

```lua
io.open(path [, mode]) -> file
```

Opens a file of the cartridge (read only) or, for paths starting with save/, a file in the game's save folder litelua/saves/<id> (read and write). Absolute paths, drives and .. are errors.

| Argument | Type | Description |
|---|---|---|
| `path` | string | e.g. "data/level1.txt" or "save/game.txt" |
| `mode` | string | "r" (default), "w", "a", "r+"... ; "b" is allowed |

Returns: file — file handle, or nil and a message if it cannot be opened

Example:

```lua
local f = io.open("save/best.txt", "w")
f:write(best)
f:close()
```

### `io.lines`

```lua
io.lines(path, ...) -> iterator
```

Iterates over the lines of a file and closes it at the end.

| Argument | Type | Description |
|---|---|---|
| `path` | string | file path, as for io.open |
| `...` | string | read formats, default "l" (one line) |

Example:

```lua
for line in io.lines("data/words.txt") do
  words[#words + 1] = line
end
```

### `require`

```lua
require(name) -> module
```

Loads a module once: src/<name>.lua, then lib/<name>.lua of the cartridge, then litelua/lib/<name>.lua shared on the SD card, then the libraries built into LiteLua. "ai.path" means ai/path.lua.

| Argument | Type | Description |
|---|---|---|
| `name` | string | module name, dots become folders |

Returns: any — the value returned by the module file

Example:

```lua
local enemy = require("enemy")
local e = enemy.new(10, 20)
```

### `dofile`

```lua
dofile(path) -> ...
```

Runs a Lua file of the cartridge every time it is called. Data files that return a table are a simple way to store levels.

| Argument | Type | Description |
|---|---|---|
| `path` | string | Lua file of the cartridge |

Returns: ... — values returned by the file

Example:

```lua
local level = dofile("data/level1.lua")
```

### `loadfile`

```lua
loadfile(path [, mode [, env]]) -> function
```

Compiles a Lua file without running it.

| Argument | Type | Description |
|---|---|---|
| `path` | string | Lua file of the cartridge |
| `mode` | string | ignored, only source code can be loaded |
| `env` | table | environment of the chunk (optional) |

Returns: function — the compiled chunk, or nil and a message

Example:

```lua
local chunk = assert(loadfile("data/script.lua"))
chunk()
```

### `os.remove`

```lua
os.remove(path) -> true
```

Deletes a save file. Only paths in save/ are allowed. os.rename(from, to) works the same way.

| Argument | Type | Description |
|---|---|---|
| `path` | string | a file in save/ |

Example:

```lua
os.remove("save/slot1.txt")
```

## System

Starting another cartridge and leaving the current one.

### `sys.run`

```lua
sys.run(name)
```

Starts another cartridge when the current callback returns. "game" finds the folder game or the file game.lcart. The current game is closed and all its memory is freed first. An error if the cartridge does not exist or its cart.lua is wrong.

| Argument | Type | Description |
|---|---|---|
| `name` | string | folder or .lcart in litelua/carts |

Example:

```lua
if btnp("start") then sys.run("mygame2") end
```

### `sys.exit`

```lua
sys.exit()
```

Closes the game when the current callback returns and goes back to the cartridge list.

Example:

```lua
if btnp("select") then sys.exit() end
```

### `sys.stats`

```lua
sys.stats() -> table
```

Performance numbers, also shown by the overlay (hold L+R, press Y). Fields: fps, cpu (% of the 33 ms frame), update_us, draw_us, draw_top_us, draw_bottom_us (microseconds), mem, mem_peak, mem_limit (Lua memory, bytes), ram_free (bytes), vram, vram_total (video memory, bytes), polys, verts (sent to the 3D engine).

Returns: table — numbers of the last frame and memory use, see below

Example:

```lua
local s = sys.stats()
if s.cpu > 90 then log("slow frame", s.update_us, s.draw_us) end
```
