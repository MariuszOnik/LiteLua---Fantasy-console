## Core

Cart callbacks, screen constants and timing.

### `_init` — callback

```lua
_init()
```

Called once after main.lua has been loaded, before the first frame.

Example:

```lua
function _init()
  x, y = 128, 96
end
```

### `_update` — callback

```lua
_update()
```

Called once per game frame (30 times per second), before drawing. Put game logic and input handling here.

Example:

```lua
function _update()
  if btn("left") then x = x - 2 end
  if btn("right") then x = x + 2 end
end
```

### `_draw` — callback

```lua
_draw(screen)
```

Called for each screen once per game frame, after _update: first with TOP, then with BOTTOM.

| Argument | Type | Description |
|---|---|---|
| `screen` | integer | TOP (0) or BOTTOM (1) |

Example:

```lua
function _draw(screen)
  if screen == TOP then
    -- draw the game
  else
    -- draw the map or the HUD
  end
end
```

### `TOP` — const

```lua
TOP
```

Top screen id (0), passed to _draw.

### `BOTTOM` — const

```lua
BOTTOM
```

Bottom (touch) screen id (1), passed to _draw.

### `print`

```lua
print(...)
```

Writes the values to the text console and to the log file litelua/log.txt on the SD card.

| Argument | Type | Description |
|---|---|---|
| `...` | any | values, separated by tabs |

Example:

```lua
print("score", score)
```

### `log`

```lua
log(...)
```

Writes the values only to the log file litelua/log.txt on the SD card, with the time since start. The file is saved once per frame; logging every frame slows the game down.

| Argument | Type | Description |
|---|---|---|
| `...` | any | values, separated by tabs |

Example:

```lua
log("enemy spawned at", x, y)
```

### `micros`

```lua
micros() -> integer
```

Time counter for measuring code speed. Wraps around after about 128 seconds, so only use it for short intervals.

Returns: integer — microseconds since boot

Example:

```lua
local t = micros()
heavy_work()
print("took " .. (micros() - t) .. " us")
```

## Input

Buttons and the touch screen. Sampled once per game frame.

### `btn`

```lua
btn(name) -> boolean
```

Button names: a b x y l r start select up down left right touch. "touch" means the screen is touched. An unknown name is an error.

| Argument | Type | Description |
|---|---|---|
| `name` | string | button name, see below |

Returns: boolean — true while the button is held

Example:

```lua
if btn("left") then x = x - 1 end
if btn("right") then x = x + 1 end
```

### `btnp`

```lua
btnp(name) -> boolean
```

Use for actions that should happen once per press (jump, menu).

| Argument | Type | Description |
|---|---|---|
| `name` | string | button name |

Returns: boolean — true in the frame the button was pressed

Example:

```lua
if btnp("a") then jump() end
```

### `btnr`

```lua
btnr(name) -> boolean
```

Use for actions on release, e.g. charged shots.

| Argument | Type | Description |
|---|---|---|
| `name` | string | button name |

Returns: boolean — true in the frame the button was released

Example:

```lua
if btn("b") then charge = charge + 1 end
if btnr("b") then shoot(charge); charge = 0 end
```

### `touch`

```lua
touch() -> x, y | nil
```

Returns the stylus position while the screen is touched, otherwise nil.

Returns: integer — x on the bottom screen (0-255); integer — y on the bottom screen (0-191)

Example:

```lua
local tx, ty = touch()
if tx then
  px, py = tx, ty
end
```

## Files

Reading cartridge files, saving data and loading modules. Paths are relative to the cartridge, "save/..." is the save folder.

### `io.open`

```lua
io.open(path [, mode]) -> file
```

Opens a file of the cartridge (read only) or, for paths starting with save/, a file in the game's save folder litelua/saves/<id> (read and write). Absolute paths, drives and .. are errors.

| Argument | Type | Description |
|---|---|---|
| `path` | string | e.g. "data/level1.txt" or "save/game.txt" |
| `mode` | string | "r" (default), "w", "a", "r+"... ; "b" is allowed |

Returns: file — file handle, or nil and a message if it cannot be opened

Example:

```lua
local f = io.open("save/best.txt", "w")
f:write(best)
f:close()
```

### `io.lines`

```lua
io.lines(path, ...) -> iterator
```

Iterates over the lines of a file and closes it at the end.

| Argument | Type | Description |
|---|---|---|
| `path` | string | file path, as for io.open |
| `...` | string | read formats, default "l" (one line) |

Example:

```lua
for line in io.lines("data/words.txt") do
  words[#words + 1] = line
end
```

### `require`

```lua
require(name) -> module
```

Loads a module once: src/<name>.lua, then lib/<name>.lua of the cartridge, then litelua/lib/<name>.lua shared on the SD card, then the libraries built into LiteLua. "ai.path" means ai/path.lua.

| Argument | Type | Description |
|---|---|---|
| `name` | string | module name, dots become folders |

Returns: any — the value returned by the module file

Example:

```lua
local enemy = require("enemy")
local e = enemy.new(10, 20)
```

### `dofile`

```lua
dofile(path) -> ...
```

Runs a Lua file of the cartridge every time it is called. Data files that return a table are a simple way to store levels.

| Argument | Type | Description |
|---|---|---|
| `path` | string | Lua file of the cartridge |

Returns: ... — values returned by the file

Example:

```lua
local level = dofile("data/level1.lua")
```

### `loadfile`

```lua
loadfile(path [, mode [, env]]) -> function
```

Compiles a Lua file without running it.

| Argument | Type | Description |
|---|---|---|
| `path` | string | Lua file of the cartridge |
| `mode` | string | ignored, only source code can be loaded |
| `env` | table | environment of the chunk (optional) |

Returns: function — the compiled chunk, or nil and a message

Example:

```lua
local chunk = assert(loadfile("data/script.lua"))
chunk()
```

### `os.remove`

```lua
os.remove(path) -> true
```

Deletes a save file. Only paths in save/ are allowed. os.rename(from, to) works the same way.

| Argument | Type | Description |
|---|---|---|
| `path` | string | a file in save/ |

Example:

```lua
os.remove("save/slot1.txt")
```

## System

Starting another cartridge and leaving the current one.

### `sys.run`

```lua
sys.run(name)
```

Starts another cartridge when the current callback returns. "game" finds the folder game or the file game.lcart. The current game is closed and all its memory is freed first. An error if the cartridge does not exist or its cart.lua is wrong.

| Argument | Type | Description |
|---|---|---|
| `name` | string | folder or .lcart in litelua/carts |

Example:

```lua
if btnp("start") then sys.run("mygame2") end
```

### `sys.exit`

```lua
sys.exit()
```

Closes the game when the current callback returns and goes back to the cartridge list.

Example:

```lua
if btnp("select") then sys.exit() end
```
