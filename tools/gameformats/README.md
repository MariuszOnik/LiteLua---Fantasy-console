# Czytniki formatów gier (prywatny użytek)

`ig/` — Imperial Glory (V3D: siatki, animacje morph, kawaleria, działa → glTF).
`m2tw/` — Medieval II (`.mesh`, animacje z `pack.idx/.dat`, wypiekanie jeźdźca na koniu → glTF).

Nasz własny kod (rozpracowane formaty); **zasoby gier nigdy nie trafiają do repo** — są
wypakowane lokalnie (`E:\AI\IG`, `E:\AI\M2TW`, ścieżki domyślne w skryptach). Opis działania,
wszystkie wywołania i przepisy: [`docs/GAME_TOOLS.md`](../../docs/GAME_TOOLS.md).
